## 2. Что добавляет KHAWTAK

### 2.1 Профиль считается формулой — лицензии не нужно

Семейство NACA 44xx по умолчанию (`researches/01` §2.2): толщина
`y_t(x) = 5t · (0,2969 √x − 0,1260 x − 0,3516 x² + 0,2843 x³ − 0,1015 x⁴)`, x = 0…1 по хорде, t — доля толщины; с
коэффициентом −0,1036 вместо −0,1015 кромка замыкается в ноль (сумма коэффициентов 0; при −0,1015 остаётся 0,0021)
[1][2]. Формула сверена с источниками 2026-11-16 — снимает пометку «по памяти» разведки 01.

**Следствие для печати [РАСЧЁТ]:** у NACA с t 12 % и хордой 100 мм толщина задней кромки 0,25 мм, на 95 % хорды — 1,6 мм,
на 90 % — 2,9 мм. Линия сопла 0,4 мм даёт стенку ≥ 0,86 мм только из двух линий (`researches/02` §0). Значит генератор
**утолщает кромку до печатной** (≥ 2 линий, ≈ 0,9–1,0 мм) — обрезает профиль там, где толщина падает ниже, и ставит
плоский торец. Потеря хорды мала, а кромку всё равно шлифуют (`researches/02` §1.1, опыт Alber 2022).

### 2.2 Сетка лопасти — набор сечений

- Станции по размаху; на каждой — замкнутый контур профиля с ОДИНАКОВЫМ числом точек (косинусное распределение по хорде,
  гуще у носка и кромки), повёрнутый на угол крутки вокруг оси шпильки на 0,40c (`researches/02` §3.1, §4.5).
- Соседние контуры сшиваются полосами треугольников; плоскости разрезов секций совпадают со станциями — торец секции и есть
  точное сечение профиля, соседние секции сходятся без ступеньки.
- Секция пишется стоя: размах по Z, корневой (широкий) торец на столе, буртик — на верхнем торце (печатается без
  поддержек), раструб снизу — открытая оболочка (`researches/02` §3.2).

### 2.3 Нутро — полости внутри тела, а не пересекающиеся тела

Вариант «своё нутро» (решение владельца, интервью 001 Q2) печатается периметрами при заполнении 0 % (`researches/02` §7.1).
Простейшая замкнутая сетка для этого — **сплошное тело с внутренними полостями**: наружная поверхность профиля плюс
замкнутые поверхности полостей с нормалями внутрь полости. Полость на станции — плоский многоугольник: профиль, сдвинутый
внутрь на толщину оболочки (с утолщениями сверху и снизу), минус кольцо трубки вокруг шпильки, разделённый перегородкой на
0,60c. Полости сшиваются по станциям так же, как наружный контур, и закрываются «крышами» 45° у торцов секции — сплошной
торец без поддержек.

**Риск — главный в сетке MVP [ОЦЕНКА]:** нужна 2D-геометрия многоугольников (сдвиг контура внутрь, вычитание круга, разрез
линией) — без библиотек, в коде страницы; и надо увидеть, что PrusaSlicer режет такое тело как задумано (периметры вокруг
каждой полости, 0 % заполнения). **Пробник фазы 2:** одна секция с двумя полостями → `prusa-slicer-console.exe --info`
(manifold) и нарезка в G-code с заполнением 0 % → взгляд на слои (снимок предпросмотра).

### 2.4 Карман закладной в вершинной секции

Решение владельца (интервью 001 Q3, ответ дословно — коммит 59793d8): шпилька вкручивается в закладную вершинной секции. Карман — ещё одна полость: прорезь
под стальную пластину с резьбой или гайку, входящая сбоку или сверху, на внутреннем (толстом) конце вершинной секции; под
ней — сплошной упор, давление на пластик ≤ 3–7 МПа (`researches/02` §5.2). Размеры гаек и толщина профиля под них —
`researches/02` §4.5 (M4 — 11,6 мм, M5 — 12,8 мм, M6 — 15,1 мм).

### 2.5 Много файлов

Три лопасти × N секций + закладные. Без библиотек — либо кнопка на каждую деталь (как в KATAK), либо ZIP без сжатия
(метод «stored»: локальные заголовки, CRC-32, центральный каталог — формат PKWARE APPNOTE) [3]. Рекомендация [AI]: ZIP
«stored» одной кнопкой плюс кнопки по деталям; одна и та же секция трёх лопастей — одна деталь ×3 (печатать одной партией,
`researches/02` §9).
